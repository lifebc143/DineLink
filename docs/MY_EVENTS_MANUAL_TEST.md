# 我的飯局管理入口：手動驗證指南

## 入口

登入正式網站後，從「個人主頁」點選 **我的飯局**，或直接開啟：

`https://dinelink-ok6woqkb.manus.space/?tab=my-events`

> 正式環境的受保護操作依使用者指示改由手動驗證；自動化測試已覆蓋 API 授權、成功回應與介面互動契約。

| 身分／情境 | 操作步驟 | 預期結果 |
| --- | --- | --- |
| 主辦人 | 開啟「我發起的飯局」 | 顯示待審核申請、已確認成員與出席紀錄。 |
| 主辦人 | 對待審核申請點選「核准」或「拒絕」 | 申請狀態更新，清單重新讀取。 |
| 主辦人 | 對已確認成員點選「出席」、「遲到」或「爽約」 | 出席狀態更新，作為後續信用／出席率資料來源。 |
| 主辦人 | 點選「查看取消規則明細」 | 展開取消、聊天室退出與出席紀錄的規則說明。 |
| 申請者 | 開啟「我已申請的飯局」 | 顯示飯局、主辦人與目前審核狀態。 |
| 申請者 | 對 pending 飯局點選「取消申請」 | 申請撤回並從可管理清單更新。 |
| 申請者 | 對 approved 飯局點選「取消參與並退出聊天室」 | 參與關係撤回、聊天室存取權移除，清單更新。 |

若登入後仍無資料，請先在「發起飯局」建立飯局，或以另一帳號對該飯局提出申請，再回到此頁進行審核與出席管理。
